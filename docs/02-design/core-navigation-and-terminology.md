# Core navigation and terminology guide

- **Status:** Implemented in WO-025A
- **Rule:** navigation names customer work; contextual links name supporting records

## Navigation

| Context | Permanent destinations                                                  |
| ------- | ----------------------------------------------------------------------- |
| Desktop | Home; Sell → Accounts, People, Interactions; Pipeline; Search; Settings |
| Mobile  | Today; Interactions; Actions; Search                                    |

Meetings, Tasks, onboarding and feedback remain compatible routes reached from the
work they support. They are not competing top-level product areas. Find, Create and
Insights are not advertised before their owning capability exists.

## Customer language

| Internal or previous label                 | Customer-facing label                     |
| ------------------------------------------ | ----------------------------------------- |
| Companies / Contacts / Opportunities       | Accounts / People / Pipeline              |
| Assistant placeholder                      | Search                                    |
| Recommended Actions                        | Next actions                              |
| Generate recommended Actions               | Prepare next actions                      |
| Proposed Action / proposal                 | Suggestion prepared for review            |
| Approved — execution requires confirmation | Approved — not sent or updated            |
| Review execution                           | Preview simulation                        |
| Execution history                          | Simulation history                        |
| Open mobile Companion                      | Prepare and start / Continue in Companion |

Technical terms remain in engineering documentation and operator diagnostics where
they are necessary. They do not form the primary label or prerequisite for an
ordinary seller workflow.

WO-025B retains the navigation table unchanged. The Search destination contains
**Search** and **Ask RevenueOS** modes; normal Search remains selected by default.
Opportunity and Account headers use **Ask about this deal/account** as secondary links.
Answer labels are **Supported by current evidence**, **Partially supported**,
**Conflicting evidence** and **Not enough reliable evidence**. Provider, RAG, vector,
prompt and retrieval terminology is absent from the seller interface.
