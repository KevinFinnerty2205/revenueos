# Forecast calibration UX

Calibration is a low-prominence explanatory section after current deal review. Each
positive seller category shows realized Won count, assessed count and a rate only at
the five-record threshold. Sparse categories say **Not enough data**.

Copy explicitly states that this is final realization rather than rep scoring or
lead-time accuracy. There is no combined accuracy score, league table, colour-coded
person ranking or target consequence. The section keeps sample size adjacent to any
percentage so a percentage cannot be mistaken for precision.
