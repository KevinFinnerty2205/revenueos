# Prospect trust-state UX

**Status:** Current WO-026 design contract

Every research observation shows one of four exact labels: **Verified**, **From
data provider**, **RevenueOS inference** or **Not established**. The label sits with
the statement, not in a remote legend, and is always readable as text.

Verified observations expose their authoritative source. Provider-supplied values
name the source as provider data and do not borrow the visual treatment of
Verified. Inference is introduced as a hypothesis and uses cautious language.
Unknown is a legitimate outcome and uses direct wording rather than an empty field
or invented placeholder.

Source disclosure sits immediately below the relevant observation when useful and
is also available in the consolidated Sources section. A source shows publisher,
title and date where known. The user can open it safely in a separate browser tab.
There is no confidence percentage or unexplained badge.

Refresh comparison uses plain categories: new, changed and no longer supported.
An earlier statement is not edited in place. This preserves the distinction between
“the research changed” and “RevenueOS changed its mind without evidence”.
