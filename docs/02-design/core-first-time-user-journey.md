# Core first-time-user journey

- **Status:** Implemented product path in WO-025A; observation with the offered cohort
  remains a Checkpoint 1B requirement
- **Outcome:** move one customer conversation forward

1. Home explains the first useful action and links to getting started when the
   workspace is empty.
2. The seller reviews the private-beta data notice and chooses an existing example or
   adds an Opportunity.
3. The seller adds the next Interaction from the deal context.
4. Interaction preparation states what matters and what to ask.
5. Companion starts deliberately. The seller can continue without recording, choose
   an authorised capture path or add allowed visual evidence.
6. After completion, the seller captures what happened and reviews the result.
7. Opportunity leads with one deal focus, then methodology gaps, evidence and a
   reviewable next action.
8. Approval records a human decision only. Any current connector preview is an
   explicit simulation.
9. Home reflects the persisted work that needs attention.

The onboarding guide mirrors this loop in five steps. It no longer requires the
seller to learn Meeting Intelligence, Revenue Brain, transcript generation or other
architecture terms before reaching value. The synthetic demo remains the safest
walkthrough, not a claim that a real design-partner environment is approved.
