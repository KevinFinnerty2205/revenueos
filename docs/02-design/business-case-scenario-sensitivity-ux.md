# Scenario and sensitivity UX

Scenario inputs sit beside eligible base inputs and are labelled Conservative and Upside. Blank overrides create no scenario. The result view uses three plainly labelled cards and lists the exact overrides; it avoids traffic lights, optimism badges and confidence scores.

Sensitivity uses one select and a labelled comma-separated set of two to five explicit points. Each result row names its input value and first highlighted output. The copy states that sensitivity does not mutate the approved base.

The Create wizard offers only **Base case + key assumptions** or **Conservative + base + upside**. This prevents an unlabelled optimistic case from becoming the default customer slide.
