# Core mobile usability review

- **Review:** WO-025A, 24 August 2026
- **Viewports:** responsive phone and desktop product walkthroughs

The former mobile shell reused eleven desktop links in a clipped horizontal strip.
WO-025A replaces it with fixed, large-target Today, Interactions, Actions and Search
navigation and reserves safe-area spacing. Main content includes bottom padding so
controls are not covered.

Home keeps the next Interaction first. Opportunity preserves the same question as
desktop but starts with deal focus and collapses administration/history. Interaction
uses one lifecycle-led primary action. Companion remains the foreground, deliberate
face-to-face surface; no background audio, system-audio or passive monitoring was
introduced. Completed recording and visual options are hidden until expanded.

The release screenshot set must confirm no horizontal page overflow, readable status
copy, visible focus, at least 44px controls, reduced-motion compatibility and usable
Home, Opportunity, Companion and post-interaction capture states.
