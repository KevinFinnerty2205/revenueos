# Standard sales methodologies

**Status:** Current RevenueOS Core behaviour from WO-024.

RevenueOS supplies concise, original v1 definitions for four commonly named sales
methodologies. These definitions organise existing Evidence; they do not reproduce
proprietary training material or claim to replace an organisation's enablement.

| Methodology | Ordered fields |
| --- | --- |
| MEDDIC | Metrics; Economic Buyer; Decision Criteria; Decision Process; Identify Pain; Champion |
| MEDDPICC | Metrics; Economic Buyer; Decision Criteria; Decision Process; Paper Process; Identify Pain; Champion; Competition |
| BANT | Budget; Authority; Need; Timing |
| SPICED | Situation; Pain; Impact; Critical Event; Decision |

Each immutable definition records a stable field key, short explanation, required or
optional status, display order, controlled canonical facts and Evidence categories,
an optional stage expectation, a bounded freshness policy and natural suggested
questions. Stage expectations are advice only and never prevent Opportunity changes.

The same validated source can appear differently across methodologies. For example,
a customer-approved pilot budget may support BANT Budget and MEDDPICC Metrics or
Paper Process only where the corresponding field policy admits it. Switching the
organisation default projects the same current source set into the new framework;
it does not require re-entry or alter Revenue Brain/Evidence history.

Standard definitions are deployed in code and cannot be edited by administrators.
A future copy or additional methodology is a new reviewed configuration/version,
not an arbitrary prompt or executable rule. Challenger, Sandler, GAP Selling and
Solution Selling are not implemented as standard projections in WO-024.
