# Oryntela do-not-build register

- **Status:** Authoritative scope guardrail
- **Consolidated:** 4 September 2026

| Do not build                                   | Why it conflicts with Oryntela                                | Allowed narrow boundary                                                    |
| ---------------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Generic project management                     | Adds unrelated concepts and administration                    | Opportunity/customer Actions only                                          |
| SharePoint/Drive/Notion clone                  | Creates a document platform instead of sales context          | Bounded files attached to sales workflows if validated                     |
| Generic BI or arbitrary report builder         | Encourages metric sprawl and unsafe interpretation            | Canonical, defined sales metrics with clear semantics                      |
| Text-to-SQL / arbitrary query                  | Creates access, correctness and explainability risk           | Typed, permission-scoped Search/Ask intents                                |
| No-code workflow/automation marketplace        | Makes sellers/admins build their own operating system         | Specific high-value, policy-bound sales workflows                          |
| Generic AI chat everywhere                     | Duplicates truth and hides authority                          | Evidence-backed Ask and contextual guided assistance                       |
| Salesforce feature clone                       | Sacrifices simplicity and differentiation                     | Minimum lovable Native CRM plus selected coexistence                       |
| Employee surveillance or rep score             | Damages trust and mistakes activity for value                 | Deal-specific, evidence-backed manager questions                           |
| Leaderboards/gamification                      | Incentivises gaming and comparison without context            | Personal and authorised organisation target progress                       |
| Private-life buyer dossier                     | Intrusive, unsafe and irrelevant                              | Sourced, relevant public professional context                              |
| Personality/emotion manipulation               | Scientifically and ethically unsafe                           | Explicit professional priorities and buyer-stated concerns                 |
| Open/click surveillance                        | Ambiguous signal with privacy/deliverability cost             | Provider send result, reply and meaningful outcome                         |
| Sender/domain rotation or spam evasion         | Undermines lawful, authentic communication                    | Approved seller identity, suppression and volume controls                  |
| Uncontrolled bulk outreach                     | Creates compliance, reputation and trust risk                 | Small reviewed Campaigns with explicit audience and stops                  |
| Autonomous cold-calling SDR                    | Identity, consent, suppression, handoff and cost are unproven | Bounded future voice only after explicit validation                        |
| Automatic research-to-customer-truth promotion | Public/inferred context is not customer Evidence              | Explicit human promotion to canonical records; Evidence remains separate   |
| AI-invented ROI/business case                  | Can create false customer claims                              | Approved inputs and deterministic calculation                              |
| AI-invented forecast or close date             | False precision and hidden authority                          | Separate seller judgement, manager view and empirical baseline             |
| Opaque deal/intent/health score                | Hides uncertainty and invites theatre                         | Explainable categorical conditions and source-linked factors               |
| Unbounded custom rules/fields                  | Expands support and mental load                               | Small typed extensions with explicit owner and limit                       |
| Full CPQ/e-signature suite                     | Outside the current evidence-to-action wedge                  | Approved pricing context and reviewed customer material only if authorised |
| Integration/app marketplace                    | Breadth before core value creates operational debt            | Partner-selected, outcome-specific adapters                                |
| New product for every projection               | Duplicates Evidence, Actions and Revenue Brain                | Reuse existing primitives for What Changed, continuity and commitments     |

This register can change only when repeated customer evidence shows an important sales
problem, the narrowest solution fits Sales Brain, and the product/security/commercial
trade-off is recorded. Competitor feature pressure alone is not sufficient.
