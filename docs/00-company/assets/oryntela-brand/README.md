# Oryntela final identity candidate assets

> **FINAL CANDIDATE — OWNER SIGN-OFF REQUIRED.** These files are the canonical
> WO-051 identity candidate for later WO-052 reuse. They are not yet production
> assets and must not replace the current application logo, favicon, metadata,
> tokens, authentication branding, documents, emails or public website.

## Selected direction

**Meridian / Direction**, using M1 as the structural base and M3 only to simplify
the small-size silhouette. The mark remains one open course plus one rising
meridian; it does not mechanically combine the two concept icons.

## Vector masters

- `oryntela-logo-primary.svg` — primary horizontal lockup and light-background
  version.
- `oryntela-logo-dark.svg` — warm-white/copper horizontal lockup for dark
  backgrounds.
- `oryntela-logo-black.svg` — black monochrome horizontal lockup.
- `oryntela-logo-white.svg` — white monochrome horizontal lockup.
- `oryntela-logo-compact.svg` — optional stacked compact lockup.
- `oryntela-wordmark.svg` — outlined title-case wordmark.
- `oryntela-symbol.svg` — primary standalone symbol.
- `oryntela-symbol-monochrome.svg` — black one-colour symbol.
- `oryntela-favicon.svg` — small-size candidate source.
- `oryntela-app-icon.svg` — transparent app-icon source with safe zone.
- `oryntela-social-profile.svg` — optional midnight social/profile treatment.

All SVG masters are self-contained paths/geometry. They contain no live text,
embedded font, raster image, filter, mask or remote asset dependency.
