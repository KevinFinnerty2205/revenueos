# Oryntela visual concept assets

**CONCEPT — NOT FINAL.** These files support the WO-051 owner selection round.
They are not approved brand assets and must not be copied into a production asset
path or used to change the product, authentication, metadata, favicon, documents,
exports or website.

## Owner-review files

- `oryntela-concept-contact-sheet.png` — all five concepts in one comparison view.
- `oryntela-concept-m1-board.png` — Meridian / Direction.
- `oryntela-concept-m2-board.png` — Meridian / Orchestration.
- `oryntela-concept-m3-board.png` — Meridian / Abstract Signal.
- `oryntela-concept-s1-board.png` — Oryntela Standard / Pure Wordmark.
- `oryntela-concept-s2-board.png` — Oryntela Standard / Wordmark + Minimal Mark.
- `oryntela-concept-review.html` — self-contained browser review page and board
  source. It has no remote runtime dependencies.

## Vector concept files

- `oryntela-concept-m1.svg`
- `oryntela-concept-m2.svg`
- `oryntela-concept-m3.svg`
- `oryntela-concept-s1.svg`
- `oryntela-concept-s2.svg`

The SVGs use simple geometry and live text. The preferred concept-round type
reference is Geist Sans, with a local system fallback in the files. No third-party
font file is distributed here. Wordmark outlines, optical kerning and final
trademark-device checks belong to the final WO-051 identity package after owner
selection.

## Palette status

Palette values shown on the boards are comparison candidates, not design tokens.
Copper/coral is decorative only in this round because white text on those accents
does not meet the normal-text WCAG contrast threshold. No colour or type decision
is approved by these files.
